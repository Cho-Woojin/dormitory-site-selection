# 결정 로그 (Decision Log)

프로젝트의 되돌리기 어려운 선택들을 기록한다. 새 세션은 이 문서를 먼저 읽고 시작한다.
결정을 바꿀 때는 기존 항목을 지우지 말고 `상태: 폐기 → D-0XX로 대체` 로 표시한다.

---

## D-001 · 가용면적 = 건축가능 연면적

**상태:** 확정 (2026-08-31)

`가용연면적 = 필지면적 × 적용용적률 × 실현계수`

- 필지 면적을 그대로 쓰지 않는다. 성북구는 1종일반주거(150%)와 3종일반주거(300%)가 섞여 있어
  같은 면적이라도 건축 가능한 연면적이 2배 차이 난다. 면적만 쓰면 사업성이 왜곡된다.
- **적용용적률은 성북구 실제 용도지역 도형을 필지에 공간조인해서 결정한다.** 구 전체 단일값 금지.
- 실현계수는 정형성·사선제한·주차 등으로 인한 미실현분을 반영하는 0~1 계수. 파라미터화한다.

**따라오는 요구:** 용도지역 데이터(`LT_C_UQ111` 또는 NSDI 국토계획구역)가 없으면 이 프로젝트는 성립하지 않는다. 데이터 확보 1순위.

## D-002 · 임대형기숙사 법규는 하드 필터로 적용

**상태:** 확정 (2026-08-31)

법적으로 임대형기숙사를 지을 수 없는 필지는 점수를 깎는 게 아니라 **후보군에서 제외**한다.

근거 법령 (검증 태스크 T-102에서 원문 대조 필요):
- 건축법 시행령 별표1 제2호(공동주택) 라목 「임대형기숙사」
  - 공공주택사업자 또는 민간임대주택법상 임대사업자가 임대사업에 사용
  - **임대 목적 실이 20실 이상**
  - 공동취사시설 이용 세대 수가 전체의 50% 이상
  - 용도상 면적 제한·층수 제한 없음
- 해당 용도지역에서 **공동주택 건축이 가능**하면 임대형기숙사도 가능

하드 필터 항목:
1. 용도지역 — 공동주택 불가 지역(1종전용주거, 녹지지역 등) 제외
2. 최소 규모 — 20실을 물리적으로 담을 수 없는 필지 제외 (D-005 참조)
3. 접도 — 건축법 제44조 접도의무 미충족 필지 제외

**트레이드오프:** 경계선상 필지가 지도에서 사라진다. 이를 보완하려고 웹 UI에서 "제외 필지 보기" 토글을 제공한다 (제외 사유를 함께 표시).

## D-003 · 웹은 MapLibre GL JS + PMTiles 정적 배포

**상태:** 확정 (2026-08-31)

GitHub Pages에는 백엔드가 없다. 그런데 사용자는 파라미터를 실시간으로 조정해야 한다.
이 둘을 동시에 만족시키는 유일한 구조:

> **점수를 미리 계산해서 굽지 않는다. 정규화된 raw 지표값을 필지 속성으로 타일에 넣고,
> 최종 점수는 브라우저에서 가중합으로 계산한다.**

- 성북구 필지는 대략 6~8만 개 → GeoJSON 전체는 수백 MB라 불가. PMTiles 벡터타일로 압축.
- PMTiles는 HTTP Range 요청만으로 동작하므로 타일 서버가 필요 없다. GitHub Pages에서 그대로 서빙된다.
- 점수 변화는 MapLibre expression 또는 `feature-state` 재바인딩으로 반영한다.
- MapLibre는 Mapbox와 달리 액세스 토큰이 필요 없다. 과금 지점이 없다.

**제약:** 타일 속성에 담는 지표 수만큼 파일이 커진다. 지표는 최종 10개 내외로 제한한다.

## D-004 · 데이터는 SHP 일괄 다운로드 중심

**상태:** 확정 (2026-08-31)

- 제공된 키 `3C4422DF-D4AE-43F1-A12C-B62F7C9CE97C` 는 브이월드 키 형식이나
  2026-08-31 기준 `data` / `search` / `address` 엔드포인트에서 `INCORRECT_KEY` 반환. **현재 사용 불가.**
- 필요한 공간데이터는 대부분 시군구 단위 SHP로 무료 배포된다. 키가 없어도 진행 가능하고,
  API보다 재현성이 높다 (호출 제한·스키마 변경에 영향받지 않음).
- 키가 살아나면 개별공시지가·건축물대장 같은 속성 보강용으로만 선택적으로 쓴다.

## D-005 · 용적률은 2025년 한시 완화를 반영하되 파라미터로 분리

**상태:** 확정 (2026-08-31)

서울시는 **2025-05-19 ~ 2028-05-18** 기간 소규모 건축물 용적률을 한시 완화 중이다.
- 제2종일반주거: 200% → **250%**
- 제3종일반주거: 250% → **300%**

오늘(2026-08-31) 기준 유효 기간 안이다. 기본값은 완화 적용(`relaxation.enabled: true`)으로 두되,
2028년 이후 시나리오를 볼 수 있게 **설정 파일에서 끌 수 있는 스위치**로 만든다.
하드코딩하면 2년 뒤 전부 틀린 결과가 된다.
