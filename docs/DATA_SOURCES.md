# 데이터 카탈로그

성북구(법정동 시군구코드 **11290**) 분석에 필요한 데이터 목록과 취득 경로.

**획득 방식 표기**
- 🟢 **스크립트** — 코드로 자동 수집 가능
- 🟡 **키 필요** — 무료 키 발급 후 스크립트 가능
- 🔴 **수동** — 포털 로그인·약관동의·신청 절차가 있어 사람이 받아야 함

받은 파일은 `data/raw/<slug>/` 에 넣고, 같은 폴더에 `SOURCE.txt`(URL·다운로드일·버전)를 남긴다.
`data/` 전체는 `.gitignore` 대상이다. 원본을 저장소에 커밋하지 않는다.

## 1순위 — 없으면 프로젝트가 성립하지 않는 데이터

### 1.1 연속지적도형정보 (필지 경계) 🔴
- **용도:** 분석의 기본 단위. 모든 지표가 이 폴리곤에 붙는다.
- **출처:** 국가공간정보포털(NSDI) 오픈마켓 → 국토정보 → 연속지적도형정보
  - https://www.nsdi.go.kr/ (오픈마켓, 시군구 단위 SHP)
- **대안:** 브이월드 WFS `LP_PA_CBND_BUBUN` (키 복구 시)
- **키 컬럼:** `PNU` (19자리 필지고유번호) — 다른 모든 데이터와 조인하는 기준키
- **좌표계:** EPSG:5186 (중부원점, GRS80). 분석은 이 좌표계에서, 웹 출력만 EPSG:4326.
- **참고:** NSDI는 `curl`로 접근 시 응답이 없다(2026-08-31 확인). 브라우저로 받아야 한다.

### 1.2 개별공시지가 🔴 / 🟡
- **용도:** S₁ 사업성의 분모(토지비).
- **출처(택1):**
  - 국가공간정보포털 → 개별공시지가 (PNU 기준 CSV, 시군구 단위) ← **권장**
  - 공공데이터포털 「국토교통부_개별공시지가정보」 오픈API (키 필요)
  - 부동산공시가격 알리미 (건별 조회, 대량 수집 부적합)
- **주의:** 기준연도를 반드시 기록한다. 매년 1월 1일 기준으로 갱신된다.

### 1.3 용도지역·지구 (국토계획구역) 🔴
- **용도:** 적용용적률 결정 + 하드필터 F1. [D-001](DECISIONS.md) 참조.
- **출처:** NSDI 오픈마켓 → 「용도지역지구도」 또는 브이월드 `LT_C_UQ111`
- **처리:** 필지 폴리곤과 **면적 가중 공간조인**. 한 필지가 두 용도지역에 걸치면
  면적이 큰 쪽을 채택하되, 걸침 여부를 플래그로 남긴다.

### 1.4 GIS건물통합정보 (건물 폴리곤 + 층수/높이) 🔴
- **용도:** S₂ 일조환경. 인접 건물의 높이와 방위가 핵심 입력.
- **출처:** NSDI 오픈마켓 → GIS건물통합정보 (시군구 단위 SHP)
- **필요 속성:** 건물 폴리곤, `층수`(GRND_FLR), `높이`(HEIGHT), 용도코드
- **높이 결측 대응:** 높이가 비어 있으면 `층수 × 층고(기본 3.0m)`로 추정한다.
  성북구 저층 주거지는 결측률이 높을 수 있으므로 추정 비율을 로그에 남긴다.
- **대안/보강:** 공공데이터포털 「건축물대장 표제부」 API — 용도·층수 보강용

## 2순위 — 지표 계산에 필요한 데이터

### 2.1 지하철역 좌표 🟡
- **용도:** S₃ 역세권 등급.
- **출처:** 서울 열린데이터광장 `subwayStationMaster` (전체 784건, LAT/LOT 포함)
  ```
  http://openapi.seoul.go.kr:8088/{KEY}/json/subwayStationMaster/1/1000/
  ```
- **상태(2026-08-31 확인):** 엔드포인트 정상 동작. 단 `sample` 키는 **한 번에 5건까지만** 반환한다
  (`ERROR-335`). **무료 인증키 발급이 필요하다** → https://data.seoul.go.kr 회원가입 후 즉시 발급.
- **범위:** 성북구 경계 + **버퍼 1.5km**. 구 밖의 역이 구 안 필지의 등급을 정하는 경우가 많다.
- **미결:** 동북선 경전철(건설 중) 포함 여부 → [Q-05](DECISIONS.md)

### 2.2 도로망 / 도로명주소 전자지도 🔴
- **용도:** 하드필터 F4(접도), S₂ 접도 보너스, 도로폭.
- **출처:** 도로명주소 개발자센터 → 도로명주소 전자지도 (시군구 단위 SHP)
  - https://business.juso.go.kr/ (개발자센터 → 주소 DB / 전자지도)
  - 위 경로의 직링크는 404였다(2026-08-31). 포털에서 현재 메뉴 위치를 찾아 받는다.
- **대안:** OpenStreetMap 도로망 (`osmnx`, 🟢 완전 자동) — 도로폭 속성은 부실하지만
  접도 판정과 보행 네트워크에는 충분하다. **1단계는 OSM으로 시작하는 것을 권한다.**

### 2.3 대학교 위치·재학생 수 🟡
- **용도:** S₄ 수요 중력지수.
- **출처:**
  - 공공데이터포털 「한국교육개발원_대학 기본정보」 (좌표·주소)
  - 대학알리미 (재학생 수)
- **대상:** 고려대, 국민대, 성신여대, 한성대, 서경대, 동덕여대, 광운대(인접)
- **현실적 대안:** 7개교뿐이므로 좌표·재학생수를 `config/universities.csv`에 **수기 입력해도 무방**하다.
  API 연동 비용이 데이터 양에 비해 크다.

### 2.4 수치표고모델(DEM) 🟢
- **용도:** 경사도 (S₄ 보조 또는 하드필터).
- **출처:** ALOS World 3D 30m 또는 SRTM 30m — `elevation` 패키지로 자동 다운로드
- **정밀 대안:** 국토지리정보원 5m DEM (🔴 신청 필요). 성북구 구릉지 분석에는 이쪽이 낫지만
  1단계는 30m로 충분하다.

### 2.5 행정동 경계 + 청년 1인가구 🔴
- **용도:** S₄ 보조 지표 (Q-06 합의 후).
- **출처:** 통계청 SGIS 행정경계 / KOSIS 인구총조사 1인가구 연령별
- **채택 미확정** — Q-06에서 결정되면 수집한다. 미리 받지 않는다.

## 인증키 현황

| 서비스 | 상태 | 조치 |
|--------|------|------|
| 브이월드 | ❌ `3C4422DF-…C97C` → `INCORRECT_KEY` (2026-08-31) | 재발급 또는 미사용 |
| 서울 열린데이터광장 | ⬜ 미발급 | **발급 필요** (지하철역 데이터) |
| 공공데이터포털 | ⬜ 미발급 | 선택 (건축물대장·공시지가 보강 시) |

```
SEOUL_OPENAPI_KEY=...
DATA_GO_KR_KEY=...
VWORLD_KEY=...
```

## 좌표계 규칙

| 단계 | EPSG | 이유 |
|------|------|------|
| 원본 지적/건물 | 5186 | 국가 표준 중부원점. 원본 그대로 보존 |
| 거리·면적 계산 | 5186 | 미터 단위. 위경도로 거리 계산 금지 |
| 웹 출력 | 4326 → 3857 | MapLibre/PMTiles 요구사항 |

거리를 EPSG:4326에서 계산하면 위도에 따라 오차가 누적된다. **분석은 반드시 5186에서 한다.**
