## ✅ 확보 완료

### 토지특성정보 (AL_D194) — 이 프로젝트의 중심 데이터
`data/raw/land_characteristics/11290/`

브이월드 국가중점데이터 (dsId=4). **필지 폴리곤·공시지가·용도지역·접도·형상·경사가 한 파일에 있다.**
당초 별도로 받으려던 연속지적도·개별공시지가·용도지역지구 3종이 이 하나로 대체되었다.

- 성북구 **52,970 필지** / 기준일 **2026-05-13** / EPSG:5186 / PNU 중복 0
- **인코딩 주의:** 속성은 CP949(EUC-KR). `.cpg` 사이드카가 UTF-8로 잘못 표기되어 있어
  `encoding='cp949'` 를 명시하지 않으면 `UnicodeDecodeError` 가 난다.

## ❌ 미확보 — 유일한 공백

### GIS건물통합정보 (건물 폴리곤 + 층수/높이)

**S₂ 일조환경 계산에 필수.** 이것 없이는 3단계 중 2단계를 만들 수 없다.

| 경로 | 링크 |
|------|------|
| 브이월드 (권장) | https://www.vworld.kr/dtmk/dtmk_ntads_s002.do?dsId=18 |
| 공공데이터포털 | https://www.data.go.kr/data/15083092/fileData.do |

- **dsId=18 확인 완료.** 토지특성정보(dsId=4)를 받았던 것과 같은 화면이다.
- API 키가 아니라 **로그인 후 다운로드**다. 시군구 목록에서 `11290 성북구` 를 고른다.
- 필요 속성: 건물 폴리곤, **지상층수**, **높이**, 용도코드
- 높이가 비어 있으면 `층수 × 층고(3.0m)` 로 추정하고, **추정 비율을 로그에 남긴다.**
  성북구 저층 주거지는 높이 결측률이 높을 수 있다.
