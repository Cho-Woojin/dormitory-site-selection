> 방법이 바뀌면 **코드보다 이 문서를 먼저 고친다.**

## 0. 핵심 구조: 가중합이 아니라 "오차범위 계층 정렬"

사용자가 정의한 탐색 방식은 가중 평균이 아니다. **우선순위가 있는 3단계 정렬**이며,
각 단계는 앞 단계의 오차범위(tolerance) 안에서만 작동한다.

```
1순위  사업성 (공시지가 대비 수익률)
         └─ 오차범위 tol₁ 안에서 동급 취급
2순위      일조환경
             └─ 오차범위 tol₂ 안에서 동급 취급
3순위          역세권 등급 (계단식)
                 └─ 같은 등급이면
                    S₁ 원값으로 최종 타이브레이크
```

> 4순위 수요 지표는 검토 후 **채택하지 않았다** ([D-008](DECISIONS.md)).
> 3단계로 이미 충분히 좁혀지고, 데이터 수집 비용 대비 순위를 바꾸는 힘이 약했다.

가중합으로 뭉개면 "사업성이 압도적인 필지가 일조 때문에 밀리는" 일이 생긴다.
계층 정렬은 그것을 막는다. **tolerance 값 자체가 웹에서 조정할 주요 파라미터다.**
`tol₁ = 0` 이면 순수 사업성 순위, `tol₁`이 커질수록 일조·역세권이 순위를 지배한다.

### 구현: 백분위 밴드 방식

```
band₁ = floor( (100 − percentile(S₁)) / tol₁ )     # tol₁ = 5 이면 5%p 단위, 0이 최상위
band₂ = floor( (100 − percentile(S₂)) / tol₂ )
grade₃ = 역세권 등급 (A~E, 이미 이산값)
최종 정렬키 = (band₁ ↑, band₂ ↑, grade₃ ↑, S₁ ↓)   # 사전식 비교
```

백분위를 쓰는 이유: S₁은 수익률(0.03~0.12), S₂는 0~1 스케일이라 절대 오차범위를 공유할 수 없다.
백분위로 정규화하면 tolerance가 두 지표에서 같은 의미("상위 몇 %p 차이까지 동급으로 볼 것인가")를 갖는다.

## 2. S₁ · 사업성 지표

### 2.1 계산식

```
토지비        = 개별공시지가(원/㎡) × 필지면적(㎡) × 실거래배율
적용용적률    = 용도지역별 상한 (A14에서 직접, D-001)
가용연면적    = 필지면적 × 적용용적률 × 실현계수
실 수         = floor( 가용연면적 × 전용률 / 실당면적 )
공사비        = 가용연면적 × 단위공사비 × (1 + 부대비율)
총사업비      = 토지비 + 공사비

보증금총액    = 실 수 × 실당보증금
순투자금      = 총사업비 − 보증금총액

연간임대수입  = 실 수 × 실당월임대료 × 12 × (1 − 공실률)
NOI          = 연간임대수입 × (1 − 운영비율)

S₁ = NOI / 순투자금
```

**보증금을 사업비에서 빼는 이유:** 보증금은 무이자 조달자금이므로 실제 투자금을 줄인다.
비용으로 보지 않고 분모에서 차감하는 것이 실무 관행이다 ([D-007](DECISIONS.md)).
실측상 보증금은 총사업비의 7% 수준으로, 수익률을 3.8% → 4.1% 로 올린다.

`분모`는 설정에서 바꿀 수 있다:
- `net_equity` (기본) — 총사업비 − 보증금. 순투자금 대비 수익률.
- `total_cost` — 보증금 무시. 통상적 Cap rate.
- `land_cost` — 토지비 기준. 사용자가 말한 "공시지가 대비 수익률"에 가장 가깝다.

세 값 모두 브라우저에서 계산 가능하므로 웹에서 전환할 수 있게 한다.

### 실측 결과 (성북구 후보 4,896 필지)

| 분모 | 중위 | 5~95% |
|------|------|-------|
| 순투자금 (기본) | **4.0%** | 2.7 ~ 5.0% |
| 총사업비 | 3.7% | 2.6 ~ 4.6% |
| 토지비 | 7.3% | 4.0 ~ 11.6% |

상위 200 필지: 2종일반 65 / 3종일반 65 / 준주거 55 / 근린상업 14 / 1종일반 1.
면적 중위 278㎡, 사업비 중위 32억, 27실. 정릉동·장위동·석관동에 집중된다.

**건전성 지표:** 수익률과 공시지가의 상관 **−0.74**, 용적률과의 상관 **+0.01**.
"공시지가 대비 사업성"을 재는 지표이므로 땅값이 지배하는 것이 정상이다.
용적률이 지배하면(D-011 이전 상태: +0.43) 지표가 고장 난 것이다.

### 2.3 실현계수 — 필지 형상·경사에서 유도 ([D-006](DECISIONS.md))

용적률 상한을 100% 소진하는 건물은 현실에 드물다. 일조사선·도로사선·주차·정형성 손실 때문이다.
토지특성정보에 **형상(`A22`)과 경사(`A20`)가 실측값으로 들어 있어** 상수 대신 이를 쓴다.

```
실현계수 = base(0.90) × 형상계수 × 경사계수
```

| 형상 (A22) | 계수 | | 경사 (A20) | 계수 |
|-----------|------|--|-----------|------|
| 정방형 | 1.00 | | 평지 | 1.00 |
| 가로장방 | 0.98 | | 저지 | 0.97 |
| 세로장방 | 0.95 | | 완경사 | 0.95 |
| 사다리형 | 0.92 | | 급경사 | 0.85 |
| 부정형 | 0.85 | | 고지 | 0.85 |
| 자루형 | 0.75 | | | |

`base = 0.90`만 가정치이고 나머지는 실측 기반이다.
실측 분포: 중위 **0.83**, 범위 0.57~0.90.

## 3. S₂ · 일조환경 지표

사용자 정의: *"바로 옆에 건축물이 있는지 없는지, 있다면 얼마나 높은지.
이런 상황이라면 도로를 면하는 건축물이 우선순위가 높을 수도 있다."*

### 3.1 물리적 근거

서울(위도 37.59°N)의 **동지 정오 태양고도 ≈ 28.97°** 이다.
남측 인접 건물을 올려다본 앙각이 이 값을 넘으면 동지에 정오 직사광이 차단된다.

```
앙각θ = atan( (인접건물높이 − 기준높이) / 수평거리 )
```

### 3.2 개방도(openness) 산출

필지 대표점에서 방위각 섹터별로 최대 앙각을 구하고, 열린 정도를 합산한다.

```
섹터: 남서 ~ 남동 (135°~225°) 를 15° 간격으로 분할
각 섹터 s 에 대해:
    θ_max(s) = 반경 R(기본 50m) 내 건물들의 최대 앙각
    open(s)  = clamp( (θ_ref − θ_max(s)) / θ_ref , 0, 1 )   # θ_ref = 28.97°

S₂_raw = Σ w(s) · open(s) / Σ w(s)        # w(s)는 정남에 가까울수록 큰 가중치
```

### 3.3 접도 보너스 — 사용자가 직접 지적한 항목

도로에 면한 방향은 **영구적으로 열려 있다.** 옆 필지는 언제든 건물이 올라갈 수 있지만
도로는 그렇지 않다. 따라서 남측이 도로면 일조가 구조적으로 보장된다.

```
S₂ = S₂_raw × (1 + road_bonus × 남측접도여부 × min(도로폭 / 12m, 1))
```

도로에 접하지 않은 방향의 나대지(현재 빈 땅)는 **미래에 건물이 설 것으로 가정**해
용도지역 상한 높이로 채워 계산하는 보수적 옵션(`assume_future_buildout`)을 둔다.
지금 옆이 비어 있다는 이유로 높은 점수를 받는 필지는 위험한 추천이다.

### 3.4 연산 비용 경고

필지 5만 3천 개 × 반경 50m 내 건물 탐색이다. 순진하게 구현하면 몇 시간 걸린다.
`geopandas.sjoin` + STRtree 공간색인 + numpy 벡터화로 처리하고, 중간 결과를 캐시한다.
이 단계는 사전 계산이며 브라우저에서 재계산하지 않는다.

## 4. S₃ · 역세권 등급 (계단식)

사용자 정의: *"역까지의 거리를 계단식으로 값을 지정해. 등급을 나눈다."*

| 등급 | 거리 | 통상 도보시간 |
|------|------|--------------|
| A | ≤ 250m | 약 3분 |
| B | ≤ 500m | 약 7분 |
| C | ≤ 750m | 약 10분 |
| D | ≤ 1,000m | 약 13분 |
| E | > 1,000m | — |

- 1단계는 **직선거리**로 산출한다. 성북구는 구릉지·막다른 길이 많아 직선거리가 도보거리를 과소평가하지만,
  전 필지 × 도보 네트워크 최단경로는 초기 단계에 과한 비용이다.
- 2단계 개선안: OSM 보행 네트워크 기반 실제 도보거리 (`osmnx`). 개선 효과가 크면 그때 도입한다.
- 임계값 4개 모두 웹 슬라이더로 조정 가능하게 한다.

### 대상 역 (성북구 및 경계 인접)

| 노선 | 역 |
|------|-----|
| 1호선 | 석계, 광운대(인접) |
| 4호선 | 한성대입구, 성신여대입구, 길음 |
| 6호선 | 보문, 안암, 고려대, 월곡, 상월곡, 돌곶이, 석계 |
| 우이신설선 | 정릉, 북한산보국문, 솔샘(인접) |
| 동북선(건설중) | 2027년 11월 개통 예정. 기본 OFF, 토글로 비교 ([D-009](DECISIONS.md)) |

구 경계 바로 밖의 역이 구 안 필지의 역세권을 결정하는 경우가 많다.

## 5. 4순위 지표는 두지 않는다

대학 수요 중력지수·청년 1인가구 밀도·경쟁공급 밀도·경사도를 모두 검토했으나
**채택하지 않기로 했다** ([D-008](DECISIONS.md)).

- 3단계로 이미 후보가 충분히 좁혀진다 (하드필터 통과 4,896).
- 데이터 수집 비용(재학생수·인구총조사·건축물대장 용도집계)에 비해 순위를 바꾸는 힘이 약하다.
- 경사도는 실현계수(§2.3)에 이미 반영되어 있어 4순위로 또 쓰면 중복이다.

**역세권 등급까지 동급인 필지는 S₁ 원값(밴딩 전)으로 최종 정렬한다.**
