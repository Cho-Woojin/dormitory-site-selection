## Phase 3 · 지표 계산

- [ ] **T-301** 하드 필터 F1~F6 구현 → `flags` 비트마스크
  - 완료조건: **필터별 제외 건수 표 출력.** 어느 하나가 90% 이상을 걷어내면 로직 재검토
- [ ] **T-302** S₁ 사업성 (총사업비 기준 + 토지비 기준 2종)
  - 완료조건: 수익률 분포가 상식 범위(3~15%). 벗어나면 파라미터 재점검
- [ ] **T-303** S₂ 일조환경 — 남측 섹터 앙각 기반 개방도
  - 완료조건: 남측이 트인 필지와 북사면 밀집지의 점수 차이를 표본 10필지로 육안 검증
  - ⚠️ 성능: 6~8만 필지. STRtree 색인 + numpy 벡터화 필수. 목표 10분 이내
- [ ] **T-304** S₃ 역세권 등급 (직선거리, 계단식 A~E)
  - 완료조건: 한성대입구역 250m 내 필지가 전부 A등급
- [ ] **T-305** S₄ 대학 수요 중력지수
  - 완료조건: 안암동(고려대 인접)이 상위, 장위동 외곽이 하위
- [ ] **T-306** 계층 정렬(오차범위 밴드) 구현 → 최종 순위
  - 완료조건: `tol₁ = 0` 이면 순위가 S₁ 단독 정렬과 **정확히 일치** (회귀 테스트)
- [ ] **T-307** 상위 20필지를 지도에서 육안 검증 **(사용자와 함께)**
  - 완료조건: 명백히 부적합한 필지가 없음. 있으면 원인을 찾아 지표 수정
