## 무엇을 푸는가

임대형기숙사(건축법 시행령 별표1 제2호 라목, 2023년 신설된 준주택)를 지을 땅을 고를 때,
"어느 필지가 좋은가"는 하나의 숫자로 답할 수 없습니다. 사업성이 좋은 땅은 대개 외곽에
있고, 역세권은 땅값이 비싸며 건물이 빽빽해 일조가 나쁩니다.

실제로 데이터에서 세 지표는 서로 반대 방향을 가리킵니다.

| 역세권 등급 | 수익률 중위 | 일조 개방도 중위 |
|---|---|---|
| A (250m 이내) | 3.75% | 0.596 |
| E (1km 초과) | 4.35% | 0.655 |

상관계수는 모두 `|r| < 0.2`로 약합니다. 세 지표가 **각자 독립적인 정보**를 담고 있다는 뜻이고,
그래서 가중 평균으로 뭉개면 안 됩니다.

## 탐색 방식: 오차범위 계층 정렬

가중합이 아니라 **우선순위가 있는 3단계 정렬**입니다.

```
1순위  사업성 (공시지가 대비 수익률)
  └ 오차범위 tol₁ 안에서 동급 취급
      2순위  일조환경 (남측 인접 건물 차폐 + 접도 보너스)
        └ 오차범위 tol₂ 안에서 동급 취급
            3순위  역세권 등급 (250 / 500 / 750 / 1,000m 계단식)
              └ 동급이면 사업성 원값으로 최종 정렬
```

**오차범위 자체가 사용자가 조정하는 핵심 파라미터입니다.**
`tol₁ = 0`이면 순수 사업성 순위가 되고, 키우면 일조와 역세권이 순위를 지배합니다.

| tol₁ | 상위 200 중 순수 사업성 순위와 겹치는 수 |
|---|---|
| 0 | 200 (일조·역세권 무시) |
| 2 | 196 |
| **5 (기본값)** | **165** |
| 10 | 86 |
| 20 | 51 (사업성이 거의 무의미해짐) |

![오차범위 0](docs/images/05-tolerance-0.webp)

*`tol = 0`. 사업성만으로 정렬한 결과.*

![오차범위 20](docs/images/06-tolerance-20.webp)

*`tol₁ = 20`. 사업성 상위권 안에서 일조와 역세권이 순위를 재배열합니다.*

### ⚠️ 자치구를 섞은 순위는 읽지 마세요

임대료를 **모든 필지에 같은 값**으로 가정하는데 성동구 후보의 공시지가는 성북구의
**1.85배**입니다. 실측 민감도는 이렇습니다.

| 성동구 임대료 | 상위 200 구성 |
|---|---|
| ×1.0 (66만원) | 성북구 197 / 성동구 3 |

## 지표 정의

### 임대료 기준: 코리빙 실거래

임대형기숙사는 신축이라 실거래 데이터가 없습니다. 운영 중인 **코리빙(공유주거)**
실거래를 벤치마크로 씁니다.

| 사례 | 전용 | 보증금 | 월 | 면적당 |
|---|---|---|---|---|
| 맹그로브 신촌 (상위) | 14.02㎡ | 500만 | 120만 | 8.56만원/㎡ |
| 에피소드 강남262 | 21.9㎡ | 1,000만 | 160만 | 7.31만원/㎡ |
| 에피소드 컨비니 신당 | 22.1㎡ | 500만 | 145만 | 6.56만원/㎡ |
| **맹그로브 신설** | ~15㎡ | 300만 | **79.8만** | 5.32만원/㎡ |

신촌·강남·신당은 정릉동이나 용답동과 입지가 다릅니다. **신설동은 성북구 보문동과
붙어 있어 유일하게 비교 가능한 벤치마크**라, 79.8만원을 16㎡로 환산해 **85만원**을
기본값으로 잡았습니다. 보증금 500만원, 운영비율 40%(관리비·공과금·인터넷·청소 포함).

> **단가를 올려도 수익률은 그대로입니다.** 66만원/운영비 25% → 85만원/운영비 40%로
> 바꿔도 중위 수익률은 3.65% → 3.64%입니다. 매출이 오른 만큼 운영비도 오릅니다.
> 코리빙은 비싸게 받는 만큼 손이 많이 가는 사업이고, 수익률이 실제로 개선되려면
> 신촌·강남급 단가를 받을 수 있는 입지여야 합니다.

### ⚠️ 일 단위 요금은 이 용도로 불가능합니다

법원은 오피스텔 단기임대를 **미신고 숙박업**으로 판단했습니다. 기준은 계약서 명칭이
아니라 영업의 실질입니다 (1개월 미만 + 반복적·영업적 제공 + 침구·청소 등 부대서비스).

임대형기숙사는 준주택이지 숙박시설이 아닙니다. 숙박시설로 전환하면
후보가 **8,602 → 1,424 (82% 감소)**하고 성수동 준공업과 일반주거지역이 전부 빠집니다.
그래서 **주택 용도 유지 + 최소 1개월**로 갑니다. 맹그로브·에피소드도 같은 구조입니다.

### S₁ 사업성

```
토지비       = 개별공시지가 × 필지면적 × 실거래배율
가용연면적    = 필지면적 × 적용용적률 × 실현계수
실 수        = floor(가용연면적 × 전용률 / 실당면적)
총사업비      = 토지비 + 공사비 + 철거비
순투자금      = 총사업비 - 보증금총액

S₁ = NOI / 순투자금
```

보증금은 무이자 조달자금이므로 비용이 아니라 분모에서 차감합니다.
분모는 총사업비 기준, 토지비 기준으로도 전환할 수 있습니다.

**적용용적률**은 서울특별시 도시계획 조례 제48조를 따르되 두 가지를 반영합니다.

- 2025-05-19 ~ 2028-05-18 소규모 건축물 **한시 완화** (2종일반 200→250%, 3종일반 250→300%)
- 상업지역 **주거용 용적률 400% 상한** (조례 별표). 임대형기숙사는 준주택이라 주거용입니다.

> 400% 상한을 빠뜨렸을 때는 상위 200필지 중 **199개가 상업지역**이었습니다.
> 용적률과 수익률의 상관이 +0.43으로, 사업성이 아니라 용적률이 순위를 만들고 있었습니다.
> 상한을 적용하자 상관이 +0.01로 떨어지고 공시지가 상관이 -0.74가 되었습니다.
> "공시지가 대비 사업성"을 재는 지표라면 땅값이 순위를 만드는 쪽이 맞습니다.

**실현계수**는 상수가 아니라 토지특성정보의 필지 형상과 지형 실측값에서 유도합니다
(정방형 1.00 ~ 자루형 0.75, 평지 1.00 ~ 급경사 0.85). 실측 분포는 중위 0.83입니다.

### S₂ 일조환경

서울의 **동지 정오 태양고도 28.97°**를 기준으로, 필지 대표점에서 남측 135~225°를
15° 섹터로 나눠 각 섹터의 최대 앙각을 구하고 개방도를 계산합니다.

도로에 면한 방향은 영구히 열려 있으므로 접도 보너스를 더합니다.
옆 필지에는 언제든 건물이 올라가지만 도로에는 그럴 수 없기 때문입니다.

검증: 접도 등급별 개방도가 **보너스를 빼고도** 단조 증가합니다.
순서를 보너스가 만든 게 아니라 실제 건물 배치가 만든다는 뜻입니다.

| 도로측면 | 보너스 전 | 최종 |
|---|---|---|
| 광대소각 | 0.854 | 0.960 |
| 중로각지 | 0.651 | 0.732 |
| 소로한면 | 0.541 | 0.563 |
| 세로각지(가) | 0.536 | 0.559 |

극단 표본도 상식과 맞습니다. 개방 상위는 성북동 저밀 단독주택지,
차폐 하위는 동선동·보문동 역세권 밀집 상업지입니다.

### S₃ 역세권 등급

성북구 및 경계 버퍼 1.5km 내 **48개 지점**까지의 직선거리를 A~E 등급으로 나눕니다.
임계값 4개 모두 웹에서 조정 가능합니다.

  국토계획법상 준공업지역에서 제한되는 공동주택은 통상 '아파트'이고 기숙사는 아파트가
  아니지만, 서울시는 준공업지역 산업기능 보호 정책을 별도로 운영합니다. 개별 확인이 필요합니다.
- **용도지역 걸침** 539건. 두 용도지역에 걸친 필지로, 넓은 쪽을 채택했습니다.

> 공장부지 386건이 통째로 빠집니다. 건축 가능 여부는 용도지역이 정하지 지목이
> 정하지 않고, 지목변경은 준공 후 신청하는 사후 절차입니다. 지금은 공장용지·

## 합필 (인접 필지 통합)

단일 필지로는 규모가 안 나오는 땅도 인접 필지를 묶으면 후보가 됩니다.
지도에서 필지를 눌러 담으면 합필 후 지표가 바로 계산됩니다.

![합필](docs/images/16-assembly.webp)

*성수동2가 299번지 5필지. 2,932㎡ 389실, 연접 확인.*

**합필의 가치는 수익률이 아니라 규모입니다.** 성동구 전역 시뮬레이션
(`scripts/08_assembly.py`, 합필 풀 13,841 · 연접 쌍 20,037 · 묶음 3,865건) 결과:

| | |
|---|---|
| 합필 이득 (합필 S₁ − 구성필지 단독 최고 S₁) | **중위 +0.12%p** |
| 성수동1가 13-22 | 단독 4.68% → 5필지 합필 4.40% |

S₁은 비율이라 규모에 거의 중립적이고, 최적 필지에 무엇을 붙여도 평균이 내려갑니다.
그래도 합필이 필요한 이유는 둘입니다.

1. **없던 후보를 만듭니다.** 상위 15개 묶음 중 4개는 구성 필지가 단독으로는
   후보가 하나도 없던 조합입니다. 규모 미달 필지 33,584개가 합필 대상입니다.
2. **거점 규모가 나옵니다.** 공유 거점 모델은 공용 커뮤니티 공간이 핵심인데
   300㎡ 단일 필지로는 안 나옵니다.

### 제약을 화면에서 알려줍니다

- **연접이 요건입니다.** 지목·지번부여지역·소유자가 같고 서로 맞닿아야 합니다.
  **도로로 갈린 필지는 합필할 수 없습니다.** 선택이 끊기면 몇 덩어리인지 표시하고,
  길 건너는 별동으로 지어야 한다고 알려줍니다.
- **준공업 3,000㎡ 이상이면 경고합니다.** 서울시 조례상 공동주택 지구단위계획
  수립 의무가 생깁니다(수년 소요). 준공업 후보의 98.4%는 3,000㎡ 미만이라
  해당 없지만, 합필하면 이 선을 넘을 수 있습니다.

실현계수는 합필 폴리곤의 **실제 형상**에서 다시 구합니다
(면적 ÷ 최소회전외접사각형 면적, 볼록껍질 + 회전 캘리퍼스). 개별 형상계수를
평균내면 합필의 정형화 효과를 놓칩니다. 타일 좌표가 격자에 스냅되므로
Python 대비 **최대 1실 / 0.049%p** 오차가 있고, 이를 검증 항목으로 고정해 두었습니다.

## 아키텍처

GitHub Pages에는 백엔드가 없는데 사용자는 파라미터를 실시간으로 조정해야 합니다.
이 둘을 동시에 만족시키는 구조는 하나뿐입니다.

> **점수를 미리 계산해서 굽지 않는다.**
> 정규화된 raw 지표값만 타일과 경량 JSON에 넣고, 최종 점수는 브라우저가 계산한다.

| 영역 | 선택 | 이유 |
|---|---|---|
| 분석 | Python + GeoPandas | 표준 공간분석 스택 |
| 좌표계 | EPSG:5186 분석 / 4326 출력 | 거리·면적은 미터 좌표계에서 |
| 타일 | PMTiles (31MB) + tippecanoe | 타일 서버 없이 정적 호스팅 |
| 지도 | MapLibre GL JS | 액세스 토큰 불필요, 과금 지점 없음 |
| 점수 | 브라우저 (`web/score.js`) | 재빌드 없이 파라미터 조정 |
| 배포 | GitHub Pages | 무료 |

전역 백분위 순위가 필요한데 벡터타일은 화면에 보이는 타일만 로드되므로,
후보가 될 수 있는 필지 41,696개의 raw 값과 **연접 관계 62,035쌍**을
`scoring.json`(6.2MB)으로 함께 싣습니다.
전체 재계산은 **10ms 안쪽**입니다.

### 정확도가 용량보다 우선

타일 용량을 아끼려고 값을 정수로 절사했다가 웹이 조용히 틀릴 뻔했습니다.
실 수는 `floor()`, 역세권은 등급 경계로 끊기므로 입력이 조금만 어긋나면 결과가 한 칸씩 튑니다.

| 양자화 | S₁ 최대오차 | 실수 불일치 | 상위200 순서 |
|---|---|---|---|
| 공시지가 천원절사 + 실현계수 ×1,000 | **6.6%p** | 490 | **114/200** |
| ×10 / ×10,000 | 5.0e-03 | 19 | 200/200 |
| **×100 / ×100,000 (채택)** | 2.3e-07 | **0** | **200/200** |

파일은 17.0MB에서 20.1MB로 3MB 늘었을 뿐입니다.

**검증된 값**

용도지역·필지형상·지형·공시지가·접도조건 (토지특성정보 실측),

실당 임대료·보증금·운영비율 (코리빙 실거래 벤치마크).

**아직 가정인 값**

단위공사비 250만원/㎡, 철거비 10만원/㎡, 전용률 0.65, 실당면적 16㎡,
공실률 0.05, 실거래배율 1.5, 실현계수 base 0.90.

이 값들을 실제 견적과 시세로 보정하기 전까지 **결과를 투자 판단에 그대로 쓰면 안 됩니다.**
웹 화면 상단의 "가정 포함" 배지는 이 사실을 알리기 위한 것입니다.

![임대료 하향 시나리오](docs/images/09-low-rent-scenario.webp)

*임대료를 45만원으로 낮추고 최소 30실을 요구하면 후보가 크게 줄어듭니다.
가정 하나가 결과를 얼마나 흔드는지 직접 확인할 수 있습니다.*

**그 외**

- 일조 분석은 인접 건물의 기하학적 차폐만 봅니다. 일조권 사선제한 등 법적 심의는 반영하지 않습니다.
- 건물 73,027동 중 21.6%는 높이·층수가 모두 없어 바닥면적으로 추정했습니다.
- 역까지 거리는 직선거리입니다. 성북구는 구릉지가 많아 실제 도보거리보다 짧게 나옵니다.
- 상업지역 비주거 의무비율(연면적 10% 이상)과 1종일반주거 층수 제한은 미반영입니다.
- 동북선 경전철(2027년 11월 개통 예정)은 역명이 확정되지 않아 기본 제외입니다.

## 다른 자치구로 확장하기

`config/params.yaml` 의 `region.districts` 에 코드를 추가하고 해당 SHP 를
`data/raw/land_characteristics/<코드>/` 에 두면 됩니다.
토지특성정보는 시군구 단위로 스키마가 같고, 조례 용적률표는 서울시 공통입니다.

```yaml
region:
  districts:
    - { code: "11290", name: 성북구, shp: "AL_D194_11290_20260520" }
    - { code: "11200", name: 성동구, shp: "AL_D194_11200_20260520" }
```

건물(AL_D010)과 개별공시지가(AL_D151)는 이미 서울 전체 파일이라 그대로 쓰입니다.
파이프라인을 다시 돌린 뒤 **반드시 상위 후보를 눈으로 확인하세요.**
지역마다 `excluded_landuse` 에 걸리지 않는 새 사례가 나옵니다.
