# 임대형기숙사 적합 필지 탐색 — 성북구

개별공시지가 대비 사업성을 기준으로 서울 성북구 전체 필지를 평가하고,
사용자가 파라미터를 직접 조정하며 결과를 탐색할 수 있는 웹 지도를 만든다.

## 무엇을 하는가

1. **지표 개발** — 임대형기숙사 사업성 평가 지표를 정의한다
2. **공간분석** — 성북구 전 필지(약 6~8만 개)에 적용한다
3. **웹 시각화** — 파라미터 조정이 가능한 지도로 결과를 공개한다 (GitHub Pages, 무과금)

## 탐색 방식

가중 평균이 아니라 **오차범위를 둔 4단계 계층 정렬**이다.

```
1순위  사업성 (공시지가 대비 수익률)
  └ 오차범위 안에서 → 2순위  일조환경 (남측 인접 건물 차폐 + 접도 보너스)
      └ 오차범위 안에서 → 3순위  역세권 등급 (250/500/750/1000m 계단식)
          └ 동급이면 → 4순위  대학 수요 중력지수
```

오차범위(tolerance) 자체가 웹에서 조정하는 주요 파라미터다.
0에 가까우면 순수 사업성 순위가 되고, 키우면 일조·역세권이 순위를 지배한다.

자세한 정의는 **[docs/METHODOLOGY.md](docs/METHODOLOGY.md)** 에 있다.

## 기술 구조

| 영역 | 선택 | 이유 |
|------|------|------|
| 분석 | Python + GeoPandas | 표준 공간분석 스택 |
| 좌표계 | EPSG:5186 (분석) / 4326 (출력) | 거리·면적은 미터 좌표계에서 |
| 타일 | PMTiles + tippecanoe | 타일 서버 없이 정적 호스팅 |
| 지도 | MapLibre GL JS | 액세스 토큰 불필요 = 과금 지점 없음 |
| 점수 계산 | **브라우저** | 백엔드 없이 실시간 파라미터 조정 |
| 배포 | GitHub Pages | 무료 |

핵심 설계: **점수를 미리 계산해 굽지 않는다.** 정규화된 raw 지표값을 타일 속성에 넣고
최종 점수는 브라우저가 계산한다. 그래서 슬라이더를 움직이면 재빌드 없이 결과가 바뀐다.

## 시작하기

```bash
uv venv && source .venv/bin/activate && uv pip install -r requirements.txt
```

```bash
brew install tippecanoe
```

데이터 취득은 [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md) 를 따른다. 일부는 포털에서 직접 받아야 한다.

## ⚠️ 한계

- `config/params.yaml` 의 사업성 가정(공사비·임대료·실거래배율)은 **아직 검증되지 않았다.**
  성북구 실제 시세로 보정하기 전까지 결과를 투자 판단에 쓰면 안 된다.
- 용적률·건폐율 표는 조례 원문 대조 전 **잠정값**이다 (작업 T-103).
- 일조 분석은 인접 건물의 기하학적 차폐만 본다. 일조권 사선제한 등 법적 심의는 반영하지 않는다.
- 역까지 거리는 1단계에서 직선거리다. 성북구는 구릉지가 많아 실제 도보거리보다 짧게 나온다.
